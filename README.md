# PeoplePulse — Employee Management System

A modern and responsive Employee Management System designed to simplify HR operations and employee administration.

## Features
- Professional HR dashboard
- Employee directory and profiles
- Department management
- Attendance tracking
- Leave request management
- Employee search and filtering
- Interactive analytics
- Dark and light mode
- LocalStorage data persistence
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Node.js / Express (backend sample)

## Run Locally
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Start using the application.

No database or backend server is required.

## Backend
A reference Express backend structure
is included in backend-sample/.
It is not connected to the frontend.

## Deployment
This project supports GitHub Pages.
An automated GitHub Actions workflow
is included in .github/workflows/.
